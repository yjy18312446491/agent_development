# 开发步骤汇报模板

以后每个功能完成后，按以下顺序汇报。

## 本步目标

说明要解决的问题、输入、输出和验收标准。

## 代码改动

列出新增、修改和删除的文件。展示关键函数或类的代码片段，并解释它们如何工作。

## 依赖和环境

列出新增依赖、版本、安装命令和安装结果。依赖未安装成功时要写明原因和替代运行环境。

## 测试和验证

列出实际运行的命令、通过数量、跳过数量、失败数量和重要输出。说明测试使用的 Python 版本。

## 工具分工

说明 Codex、Cursor、Grok 和 VS Code 终端分别做了什么。只读审查结果要说明是否采纳。

## Git 记录

说明当前分支、commit SHA、commit message、改动文件数和增删行数。

## GitHub 状态

说明远程分支、Pull Request 链接、变更文件、检查状态和是否合并到 `main`。

## 限制和下一步

列出当前未完成部分、已知限制和下一步会新增的文件。
