# 项目状态

## 当前功能分支已实现

- PDF 文本和候选人字段抽取
- 文本质量闸门
- 基于合成 JD 的确定性岗位路由
- 五维规则评分，项目分使用离线 Mock，默认为 0
- 评分结果校验，检查分项、总分与岗位 ID，保留合法的上游复核结果
- 单份 PDF 筛选入口，从 PDF 返回经校验的评分或人工复核结果
- 合成 PDF 文件状态、中文简历画像和抽取至评分校验的回归测试
