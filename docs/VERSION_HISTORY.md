# 版本历史

下面只保留功能版本、遇到的问题和改进内容。每个 commit 都可以用 Git 查看和回退。

| 版本 commit | 遇到的问题 | 具体改进 |
|---|---|---|
| `5833647` | 项目还没有 Python PDF 抽取基础 | 增加 `extract_pdf`、文本清洗、依赖配置和基础测试 |
| `8ec4943` | 还不能从简历生成候选人画像 | 增加姓名、工作年限、学历和技能抽取 |
| `d2046b9` | `Go` 会误命中 `Django`、`Google`、`good` | 增加英文技能边界匹配 |
| `586be41` | 教育日期被算工龄，连续工作区间计算错误，标题被识别为姓名，否定技能仍会命中 | 修复工龄并集、教育和出生年份排除、学历默认分、姓名过滤和否定语句技能抽取 |
| `a69ac5d` | 空 PDF、扫描碎片、损坏文件和过短简历可能进入评分 | 增加文本质量闸门，区分 `EMPTY`、`SUSPECT_SCAN_OR_CORRUPT`、`EXTRACT_ERROR`、`TOO_SHORT`，拦截时使用 `score=-1` |
| `7f23911` | 简历没有稳定的岗位分配逻辑 | 增加岗位配置、稳定 `jd_id`、技能和年限确定性路由 |
| `82358d6` | 四年候选人可能被分到初级岗位，测试和运维词可能误伤后端简历，重复岗位 ID 没有校验 | 超过岗位上限时排除岗位，收窄方向词，校验重复 ID，保留 `UNMATCHED` 路由指标并补充边界测试 |
| `263da98` | 合成 PDF 和中文画像源文件的测试职责容易混淆，中文提示型扫描件的当前口径缺少回归 | 明确 PDF 使用英文夹具、中文画像使用 `.txt` 源文件，拆分画像测试并锁定中文提示型扫描件按 `TOO_SHORT` 处理 |
